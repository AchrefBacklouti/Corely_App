# Fitness App

A mobile/desktop fitness application to help users track workouts, plan weekly routines, and monitor progress.

## Features

- **Workout Plans:** Predefined full-week workout routines for strength, cardio, and flexibility.
- **Track Progress:** Log daily exercises, sets, and reps.
- **Custom Workouts:** Add and manage custom exercises.
- **Statistics:** View progress over time with charts and summaries.
- **Notifications:** Reminders to complete daily workouts.
